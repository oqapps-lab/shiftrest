## Проблема скрипта (причина обрыва)

Скрипт `take_screenshots.ps1` сделал `Tap 950 200` (иконка gear) в конце прохода по Today, затем вызвал `Back`. Это открыло меню Expo Go или уровень выше приложения, и `Back` вернул на Android home screen. Приложение вышло из Expo Go.

**Исправление применено в Проходе 2** — скрипт `take_screenshots_p2.ps1` не вызывает `Back` из основных вкладок.
