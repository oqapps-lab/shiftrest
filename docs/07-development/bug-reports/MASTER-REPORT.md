## B01 — Поле имени принимает бесконечный текст без ограничений

**Где:** Онбординг, шаг 10 → поле "What's your name?"

**Что вижу:** В поле имени можно ввести текст любой длины — строка из сотен символов уходит далеко за пределы поля. Никакого ограничения нет, кнопка Continue при этом остаётся активной.

**Как должно быть:** Поле должно принимать только разумное имя — до 50 символов. Если введено слишком много — кнопка Continue блокируется или появляется подсказка.

## B22 — Бесконечный цикл setState в transition.tsx: Console Error "Maximum update depth exceeded"

**Где:** Вкладка Today → плашка TRANSITION IN PROGRESS → открыть модальное окно → подождать несколько секунд

> Maximum update depth exceeded. This can happen when a component calls setState inside useEffect, but useEffect either doesn't have a dependency array, or one of the dependencies changes on every render.

Call Stack: `useEffect$argument_0` в `transition.tsx` → `dispatchSetState` → бесконечный цикл `commitPassiveMountOnFiber` / `recursivelyTraversePassiveMountEffects`. Ошибка блокирует весь экран красным диалогом.

**Как должно быть:** Модальное окно Transition должно открываться и работать без ошибок. Никаких Console Error.
