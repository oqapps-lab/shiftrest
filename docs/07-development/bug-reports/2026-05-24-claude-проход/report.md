## B1 — Доза мелатонина: непонятно, что выбрано по умолчанию

**Где:** Шаг 8 из 10 "Do you take melatonin?" → переключатель включён → раздел "DOSE (MG)"

**Что вижу:** Когда включаешь переключатель, появляются кнопки с дозами: 0.5 / 1 / 3 / 5 / 10. Ни одна из них не выглядит нажатой или выбранной — все одинакового светло-серого цвета. Кнопка "Continue" при этом активна и пускает дальше. Для сравнения: в разделе "USUAL TIME" кнопка 22:00 выделена правильно.

**Как должно быть:** Кнопка 0.5 (значение по умолчанию) должна выглядеть выбранной сразу при включении переключателя — тёмный фон, как у выбранной кнопки времени.

**Примечание:** В настройках профиля (Sleep preferences → Melatonin) кнопка 0.5 отображается правильно — с тёмным фоном. Баг только в онбординге.

**Скриншот:** `screenshots/23-step8-melatonin-on.png`

**Приоритет:** MEDIUM

## B2 — Добавление смены: тип "Ночная" не меняет время начала и конца

**Где:** Расписание → кнопка "+ Add shift" → раздел "SHIFT TYPE"

**Что вижу:** По умолчанию выбрана "Day": START = 07:00, END = 19:00. Переключаешь на "Night" — и START остаётся 07:00, END остаётся 19:00. Время не меняется.

**Как должно быть:** При выборе "Night" время должно автоматически переключаться — START = 19:00, END = 07:00 (или аналогичное ночное время).

**Скриншоты:** `screenshots/38-add-shift-day.png`, `screenshots/39-add-shift-night-bug.png`

**Приоритет:** MEDIUM

## B3 — Кнопка "Restart onboarding (dev)" видна всем пользователям

**Где:** Профиль → прокрутить до низа настроек

**Что вижу:** В самом низу настроек есть кнопка "Restart onboarding (dev)" с подписью "Wipe quiz answers and replay from S02". Это служебная кнопка разработчиков — она сбрасывает все ответы из анкеты.

**Как должно быть:** Кнопка должна быть полностью скрыта от пользователей и доступна только в dev-режиме (__DEV__ === true).

**Скриншот:** `screenshots/46-profile-scrolled.png`

**Приоритет:** HIGH

## B4 — У нового пользователя сразу статистика как у опытного

**Где:** Профиль → блок со статистикой вверху

**Что вижу:** Только что прошёл онбординг первый раз, а приложение показывает: 42 дня, 3 плана, 98% выполнения, 14 заполненных точек стрика. Это моковые данные, которые не убраны из продакшн-вида.

**Как должно быть:** У нового пользователя должны быть начальные значения: 0–1 день, 1 план, 0 дней стрика.

**Скриншот:** `screenshots/45-profile.png`

## B5 — Профиль: лишняя точка в строке с профессией

## B6 — Ползунок COMMUTE TIME сдвигается при прокрутке страницы

**Где:** Профиль → Sleep preferences → раздел "COMMUTE TIME"

**Что вижу:** При обычной прокрутке страницы вверх (свайп) ползунок COMMUTE TIME автоматически сдвинулся с 30 минут на 45 минут. Жест прокрутки был захвачен ползунком вместо ScrollView — значение изменилось без намеренного взаимодействия пользователя.

**Как должно быть:** Прокрутка страницы не должна менять значение ползунка. Ползунок должен реагировать только на прямые горизонтальные жесты по нему.

**Скриншоты:** `screenshots/50-sleep-prefs-scrolled3.png` (30 min), `screenshots/52-sleep-prefs-slider-moved.png` (45 min)

**Приоритет:** MEDIUM
